# 在 Magpie 中保留原有网关职责

以 Codex Desktop、CCS 直连配置和千刀网关配合使用的效果为基准，采用 Magpie Provider 插件承担千刀请求与错误恢复，由请求中间件关联同一次客户端请求，使宿主重复调用时共用重试次数、期限和终止状态。请求使用用户填写的千刀地址，避免跨站切换；整个插件共用可调整的并发上限，初始为 5。

插件注册独立的“千刀网关”供应商，用户通过选择该供应商的模型启用它。

## 已知限制

Magpie 0.1.4795 的“错误原样转发”不支持 Provider 插件。共享预算约束实际发往千刀的请求量，宿主仍可能对最终错误继续等待或标记账号暂歇；客户端重新发起的请求属于新的预算，仍受插件共用冷却和并发约束。
